# Совместная игра «Атлас чудес»

Готовы сервер, страница входа по коду комнаты и совместная игра на 100 уровней.
Два участника: Землерой собирает корни и разбивает камни, Мохопых раскрывает бутоны.
Регистрация, почта, имя и чат не используются. Случайный код комнаты — 8 символов.
Токен участника хранится в sessionStorage и не отображается в комнате.
Комнаты удаляются после 30 минут без запросов. Перезапуск сервера сбрасывает комнаты.

## Проверка

Из корня проекта:

```sh
node multiplayer/test.cjs
PORT=10001 ALLOW_LOCAL=1 node multiplayer/server.cjs
```

Для размещения на Render: Node, бесплатный тариф, build command `node --check atlas/multiplayer/server.cjs`, start command `node atlas/multiplayer/server.cjs`.
В GitHub файлы сервера должны находиться в `atlas/multiplayer/`.
Сервер слушает `0.0.0.0:$PORT`, проверка состояния: `/health`.
Не устанавливать ALLOW_LOCAL на публичном сервере. Разрешённый браузерный источник: `https://xrohlya.github.io`.
В `multiplayer-config.js` нужно записать HTTPS-адрес созданного сервиса.
После запуска проверить создание комнаты с двух отдельных сеансов и общую игровую карту.
Страницу и ссылку на неё публиковать после подключения и проверки сервера.

## Состояние

Проверены все 100 совместных карт, вход двух игроков, ограничение комнаты двумя участниками,
проверка токенов, синхронизация состояний и запрет преждевременного перехода уровня.
Сервер: https://atlas-creatures-coop.onrender.com. Тариф free, автоматические развёртывания отключены.
Для новых изменений сервера требуется вручную запустить deploy.
Создатель комнаты может вызвать Мохопыха-бота до присоединения второго игрока.
