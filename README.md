# Голос — демонстрационный мини-апп

Интерактивный статический прототип голосового Telegram Mini App для демонстрации заказчику.

Фирменная палитра:

- `#3515B0` — сине-фиолетовый
- `#FF4C00` — оранжевый
- `#F0FC00` — салатовый
- `#ede8e0` — фон

Что можно посмотреть:

- главный экран;
- выбор режима «С ходу» / «Глубоко»;
- выбор тем;
- реролл темы;
- подготовка;
- таймер записи;
- завершение тренировки;
- прогресс;
- профиль;
- экран покупки разборов.

Это frontend-демо. Backend, Telegram WebApp API, запись реального аудио и нейроразбор не подключены.
